
0.	Предварительно на ПК установлены IntelliJ и Docker. Предполагается, что юзер обладает любительскими навыками пользования ПК.
1. Запустить Docker.
2.	Запустить cmd/PowerShell от имени администратора и выполнить команду:
docker run -d --name reqres-postgres -e POSTGRES_DB=reqres_db -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=admin -p 5431:5432 postgres:15

(где:
docker run                      - создание и запуск контейнера из image (если image нет, он скачается)
-d                              - запуск в фоне без отображения логов процесса запуска
--name reqres-postgres          - имя создаваемого контейнера (юзер указывает его сам)
-e POSTGRES_DB=reqres_db        - имя создаваемой БД в контейнере
-e POSTGRES_USER=postgres       - имя пользователя для доступа к БД (без указания имя postgres)
-e POSTGRES_PASSWORD=admin      - обязательный пароль, указываемый пользователем для доступа к БД внутри контейнера (без него image не запустится)
-p 5431:5432                    - проброс порта (порт на хосте:порт в контейнере)
postgres:15                     - image для развёртывания контейнера (название:версия))

3. Запустить IntelliJ и настроить подключение к БД контейнера:
- в IntelliJ справа меню Database
- New > DataSource > PostgreSQL
Заполнение строк:
- Host: localhost
- Port: порт на хосте, указанный ранее в команде docker run
- User: имя пользователя для доступа к БД, указанное ранее в команде docker run
- Password: пароль для доступа к БД, указанный ранее в команде docker run
- Database: имя созданной БД, указанное ранее в команде docker run
- URL: заполняется автоматически при заполнении строки Database
- Кнопка Test Connection - в случае успеха, нажать Apply > OК

4. Выполнить все тесты класса ReqresTest, убедиться что не падает с ошибками.
